# Authentication System

A full-stack authentication system built with React,
Node.js, Express, MongoDB, JWT and Resend.

## 🚀 Live Demo

Frontend:
https://authentication-system-ram.netlify.app

Backend:
https://authentication-system-api-r11t.onrender.com

## ✨ Features

- User registration
- Email verification
- Secure login
- JWT authentication
- Refresh tokens
- Forgot password
- Password reset
- Change password
- Profile management
- Delete account
- Protected routes
- Rate limiting
- Input validation
- Security headers
- Production deployment

## 🛠️ Tech Stack

### Frontend
- React
- Vite
- React Router

### Backend
- Node.js
- Express
- JWT
- Express Validator

- Express Rate Limit

### Database

- Netlify
- Render
- MongoDB Atlas
